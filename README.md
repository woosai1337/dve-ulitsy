# Улица Полины Гельман

Квест-история о гомельчанке **Полине Гельман** — штурмане 46-го гвардейского полка «ночных ведьм», Герое Советского Союза.

Конкурсная работа для областного конкурса ОО «БРПО» «Гордость Беларуси: образ женщины» (квест-история), номинация №1 «Женщина-герой».
ГУО «Средняя школа №22 г. Гомеля», Советский район, пионерская дружина имени Гриши Подобедова. Автор — Терещенко Матвей, 5 «В» класс.

## Что на сайте

- **Первый экран** — фотоколлаж: настоящий самолёт По-2 со штурманом и портрет Полины Гельман. Сверху — лента с белорусским национальным орнаментом и полосами флага.
- **Героиня** — одна судьба: от гомельской школы и аэроклуба до Золотой Звезды.
- **Квест «Шесть остановок одной судьбы»** — маршрут от детства в Гомеле до улицы её имени в Советском районе. В каждой остановке один вопрос; прогресс сохраняется в браузере.
- **Полк «ночных ведьм»** — фотогалерея 46-го гвардейского полка.
- **Хроника** — от 1919 года до 2015 года.
- **Гомель помнит** — улица, мемориальная доска, аэроклуб, музей военной славы.
- **О Годе белорусской женщины**, о конкурсной работе и **источники**.

## Файлы

- `index.html` — разметка страницы
- `css/style.css` — оформление: светлая тема, серифные заголовки, маршрут квеста
- `js/data.js` — весь контент: героиня, квест, хроника, источники
- `js/app.js` — сборка страницы, логика квеста, кнопки «поделиться»
- `assets/photos/` — фотографии с указанием лицензий
- `assets/ornament.png` — белорусский орнамент для ленты (с флага, общественное достояние)
- `assets/og.jpg` — картинка для превью в соцсетях

## Публикация

GitHub Pages, ветка `main`, каталог `/(root)`. Файл `.nojekyll` уже на месте.

## Правка контента

Почти всё содержимое — в `js/data.js`. Чтобы поменять тексты, добавить остановку квеста или источник, правьте только этот файл: страница собирается из него автоматически.
